# 기존 UI(develop) 대비 현재 UI(merge)에 빠진 기능 대조표

`integration/ui-develop-merge`(이하 **현재 UI**)는 `poolhan/ui-improvement`의 화면 위에
`origin/develop`(이하 **기존 UI**)을 병합한 결과다. 병합 과정에서 UI 브랜치 쪽 페이지가
이겨서, **기존 UI가 보여주던 정보 일부가 화면에서 사라졌다.** 이 문서는 그 목록을 하나씩
캡처해 정리한 것이다.

## 먼저 알아 둘 것

- **파일이 지워진 게 아니다.** `web/src`에서 develop 대비 삭제된 파일은 **0건**이다.
  유실은 전부 "페이지가 그 컴포넌트를 더 이상 호출하지 않는다"이다.
  `main.jsx`부터 import 그래프를 따라가면 develop에서 살아 있던 **24개 파일이 현재 UI에서
  도달 불가**다.
- **현재 UI가 ui-improvement에서 잃은 것은 없다.**
  `(ui-improvement 도달 가능) − (현재 UI 도달 가능)` = 공집합. 병합 자체는 UI 측면에서 무손실이다.
- 따라서 이 문서의 대상은 **develop → 현재 UI 방향의 유실**뿐이다.

## 캡처 기준

| 항목 | 값 |
|---|---|
| 기존 UI | `origin/develop` (8eb975f) |
| 현재 UI | `origin/integration/ui-develop-merge` (38c9d14) |
| 뷰포트 | 1440×1000, 2배 해상도 |
| 지역 | 영월(`yeongwol`) 기본, 사례 전용 계약이 필요하면 거제(`geoje`), 생애주기 스키마는 충주(`chungju`) |
| 캡처 방식 | Playwright 요소 단위 크롭. 접이식(`<details>`)은 펼친 상태 |

## 판정 표기

| 표기 | 뜻 |
|---|---|
| **없음** | 현재 UI 어디에도 같은 정보가 없다 |
| **부분** | 일부만 남았다 (무엇이 빠졌는지 각 항목에 적었다) |
| **중복** | 현재 UI가 같은 정보를 다른 형태로 이미 보여준다 → 이식 불필요 |

| 생애주기 패널 | 목업 전용 스키마이고 현재 UI에 대체 화면이 있다 |

# 부록 · 재현 방법

```bash
# 두 리비전을 별도 워크트리에 띄운다 (현재 작업 브랜치를 건드리지 않는다)
git worktree add <임시경로>/ui-develop origin/develop
git worktree add <임시경로>/ui-merge   origin/integration/ui-develop-merge
# 각 워크트리의 web/ 에 node_modules 를 링크한 뒤
npx vite --port 5201   # develop
npx vite --port 5202   # merge
```

캡처는 Playwright 요소 단위 크롭(뷰포트 1440×1000, 2배 해상도)이다.
대상 목록과 스크립트는 리포에 남기지 않았다 — 위 절차로 언제든 다시 만들 수 있다.

도달 그래프(무엇이 죽었는지)는 `web/src/main.jsx`부터 상대 경로 import를 따라가
파일 집합과 차집합을 내는 방식으로 계산했다.
