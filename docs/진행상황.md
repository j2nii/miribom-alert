### JSON 스키마 9종 확정 (`data/schema/`)
`signal_status` `forecast` `visitor_profile` `hotspots` `content_type` `checklist` `precedent` `before_after` `timeline`

모든 파일이 공통 봉투를 따른다:
```json
{ "_mock": true, "source": [...], "period": {...}, "caveat": [...], "data": {...} }
```
`source`·`period`·`caveat`가 **스키마 레벨 필수**다. 즉 출처 없는 값은 구조적으로 화면에 올라갈 수 없다.

### 목업 JSON 9종 (`data/mock/`)
거제 기준. 값은 가짜지만 자릿수·날짜범위·항목수는 실제와 유사하게 맞췄다. forecast는 90일치 실제 생성.

## 팀원별 다음 액션

### 역할3 (프론트엔드)
**지금 바로 시작 가능하다. 기다릴 것이 없다.**

1. `data/schema/`에서 9종 스키마 확인 — 화면에 뭐가 들어올지 여기에 다 있다
2. `data/mock/`의 목업 9종으로 화면을 만든다. 실데이터가 와도 **같은 파일명·같은 구조**로 교체되므로 코드 수정이 필요 없다
3. 공통 컴포넌트를 먼저 만들 것: `source` / `period` / `caveat` 표시 배지, `_mock: true`일 때 샘플 데이터 배너
4. `data/prod/content_type.json`은 **이미 실데이터다.** AREA 2 화면은 목업이 아닌 진짜 데이터로 만들 수 있다

우선순위: Vercel 배포 URL 확보 → AREA 0 관제 대시보드 → 나머지 4개 화면 골격

### 데이터팀 (매뉴얼 구조화)
1. `manual/README_태그체계.md` 읽기 — 필드 설명과 값 목록이 전부 정리되어 있다
2. `manual/checklist_items.sample.json`의 샘플 5건과 **완전히 같은 형식**으로 나머지를 채운다
3. 결과를 `manual/checklist_items.json`으로 저장
4. 검증: `uv run python scripts/validate_manual.py`

뽑을 위치와 예상 건수는 README에 표로 정리되어 있다 (p.50에서 17건, p.13에서 12~16건, p.20에서 25건 내외).

**중요**: 조치 문장을 요약하거나 다듬지 말 것. 매뉴얼은 공공누리 4유형(변경금지)이며, 원문 그대로 옮기고 쪽수를 남기는 것이 이 프로젝트의 신뢰성 근거다.

## 주요 결정 사항

| 결정 | 이유 |
| --- | --- |
| JSON 키는 영문, 매뉴얼 구조화 산출물만 한글 키 | 전자는 React가 소비하는 계약, 후자는 사람이 손으로 채우는 파일 |
| 단계 축을 `alert_level`(관심·주의·경계·심각)과 `congestion_level`(1~5)로 분리 | 매뉴얼이 두 체계를 별도로 쓴다. 전자는 경보, 후자는 밀도 측정 등급 |
| `content_type`에 `예능·방송 노출형` 추가 | 거제 사례의 진원지가 이 유형이며 확산 속도가 가장 빠르다 |
| `content_type`에 `관광무관` 추가 | 지역명만 겹치는 콘텐츠를 걸러내되 **제외 건수를 표시**하기 위해 |
| `before_after`의 KPI를 매뉴얼 11개 지표 enum으로 고정 | 우리가 성과 지표를 지어낼 수 없게 구조적으로 차단 |
| `data/prod/*.json`은 gitignore 예외로 추적 | 웹이 직접 읽는 제품이며 건당 수 KB |

## 산출물 위치

```
data/schema/       9종 스키마 + 공통 봉투          ← 계약. 변경 시 양쪽 합의 필요
data/mock/         목업 9종 (거제)                ← 역할3가 화면 만들 때 사용
data/prod/         실데이터 산출물                 ← content_type.json 완료
data/raw/youtube/  수집 원본 (gitignore)
manual/            태그 체계 + 샘플 5건            ← 데이터팀 작업 대상
agents/prompts/    에이전트 프롬프트
docs/manual-source/ 매뉴얼·연구보고서 PDF + 출처 안내
```

### 실행 명령

```bash
uv sync                                          # 환경 구성

uv run python collection/youtube_collect.py --region 거제   # 유튜브 수집
uv run python agents/agent2_apply.py                       # 에이전트② 결과 반영
uv run python scripts/gen_mock.py                          # 목업 재생성

uv run python scripts/validate_data.py data/mock           # 데이터 계약 검증
uv run python scripts/validate_manual.py                   # 매뉴얼 구조화 검증
```

`.env`에 `YOUTUBE_API_KEY`가 필요하다 (`.env.example` 참고). 쿼터는 하루 10,000 units이고 검색 1회가 100 units다.
