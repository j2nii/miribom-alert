## 1. 역할1에게 — 유튜브 수집 스크립트

```
[역할4] 유튜브 수집 스크립트 공유드려요 — W1의 "YouTube 8곳" 새로 안 짜셔도 됩니다.

repo agents 브랜치 받고 uv sync 한 번 하시면 돼요.
  uv run python collection/youtube_collect.py --region 여수 --comments --days 220

· 검색어는 {지역} 여행 / 가볼만한곳 / 맛집 3종으로 고정돼 있어요 (지역명만 바꾸면 됨)
· --comments 붙이면 댓글 작성 시각까지 저장돼서, W1에서 말한 "과거 조회수 없음 → 게시일+댓글 시각으로 대체"가 그대로 됩니다
· 실행하면 쿼터 사용량이 자동으로 찍혀요. 하루 10,000 units, 1회 실행에 약 300~400
· 결과는 data/raw/youtube/{지역}_{시각}.json

거제는 이미 끝났고 나머지 7곳만 돌리시면 됩니다.

API 키가 필요한데, 본인 키를 발급받으시는 걸 추천해요 (Google Cloud Console, 5분).
키마다 쿼터가 따로라 하루 쿼터가 두 배가 됩니다. 발급 후 .env에 YOUTUBE_API_KEY=... 넣으시면 돼요.
제 키 쓰실 거면 개인톡 주세요 (단톡·repo에는 올리지 않을게요).

자세한 건 docs/진행상황.md '팀원별 다음 액션 > 역할1' 참고해 주세요.
```

## 2. 역할1·2에게 — 매뉴얼 구조화 (수집 끝난 뒤)

```
[역할4] 매뉴얼 구조화 부탁드립니다 — 데이터 수집 일단락된 뒤에 해 주시면 돼요.

원래 전체를 부탁드리려 했는데, 에이전트③ 테스트에 필요해서 35건은 제가 먼저 채웠어요.
(p.50 체크리스트 17 / p.20 시나리오 ①② 8 / p.13 유형별 관리 4 / p.39 상황별 대응 4 / p.37 2)

남은 범위만 부탁드려요:
· p.20 시나리오 ③~⑦ (20건)
· p.18~19 운영관리 계획 수립
· p.35 교육·훈련, p.38 관광객 안전 관리
· p.40 관광지 유형별 대응 (8건 내외) ← 데드존 분산 조치가 여기 있어서 우선순위 높아요

방법
1. manual/README_태그체계.md 읽기 (필드 설명, 값 목록, id 대역 표)
2. manual/checklist_items.json에 이미 35건 있어요. 같은 파일에 이어서 추가
3. 검증: uv run python scripts/validate_manual.py

꼭 지켜 주세요
· 조치 문장을 요약·수정하지 말고 원문 그대로 (공공누리 4유형 변경금지)
· PDF에 텍스트가 없어서 복사가 안 돼요. 작은 글씨는 확대해서 확인해 주세요
  (p.20의 "우천"이 원본 크기로 보면 "주전"처럼 보여요)
· "4단계 감지 시"처럼 조건 있는 현장 조치는 혼잡도단계를 [4,5]처럼 조건만 넣기
  → 이게 있어야 유튜브·검색량만 보고 "출입구 통제"가 추천되는 사고를 막아요

분담은 편하게 나눠 주세요. 막히면 저한테 물어봐 주세요.
```

## 3. 역할3에게 — 계약 변경 알림

```
[역할4] 스키마에 필드가 조금 늘었어요 — 전부 선택 필드라 기존 코드는 안 깨집니다.

새 파일
· briefing.json (10번째) — AREA 3 상단 브리핑. data/mock/, data/prod/ 둘 다 있어요
  paragraphs 3개(현재 상황 / 예상 전개 / 권고 조치) 순서 고정, 400~600자
  facts 배열에 문장 속 숫자의 출처가 있어요 → 수치 옆에 출처 툴팁 붙이면 좋습니다

checklist.json
· items[].status: "발동" / "대기"
  대기 = 경보 단계는 맞는데 현재 혼잡도가 모자라 아직 실행 안 하는 조치
  → standby_condition("혼잡도 4단계 이상 관측 시")과 함께 따로 묶어서 보여 주세요
· items[].relevance: "핵심" / "관련" / "일반"
· items[].phase에 "사전(예보 대응)" 추가 (기존 4개 앞)
· data.assessment: 예상 혼잡 상황 유형 + 매뉴얼 범위 밖 이슈(바가지 등)
  → AREA 3에 짧게 띄우면 "AI가 정책을 안 만든다"는 걸 보여 주는 장면이 돼요
· rank는 전체 순위라 '핵심'이 뒤로 가는 경우가 있어요. 화면은 시점별로 묶어서 보여 주세요

signal_status.json
· cross_validation[].stage: "관심" / "의도" / "실현" (신호등 3칸 라벨로 쓰시면 됩니다)
· escalation: 다음 단계로 오르는 조건과 충족 여부

prod의 checklist.json·briefing.json은 입력이 아직 목업이라 _mock: true예요. 배너 뜨는 게 정상입니다.
```
