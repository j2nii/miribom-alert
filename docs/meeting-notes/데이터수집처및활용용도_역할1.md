# 데이터 수집처 및 활용 용도

## 1. 한국관광 데이터랩 (datalab.visitkorea.or.kr)

| 수집처 (경로) | 데이터 | 활용 용도 |
| --- | --- | --- |
| 지역별 관광현황 › [소셜미디어] 탭 | SNS 언급량(채널별), 동반유형 언급량·키워드, 여행유형/트렌드 언급량 | ① 관심 신호 판정, ④ 동반유형·여행유형 프로파일 |
| 빅데이터 › 내비게이션 › 지역별 검색건수 | 목적지 유형별 검색량 | ② 의도 신호 판정 |
| 빅데이터 › 이동통신 › 지역별 방문자수 / 지역별 관광현황 [방문자] 탭 | 방문자수 추이(내·외국인) | ③ 실현 신호 판정, ⑦ 조치 전후 비교 |
| 지역별 관광현황 › [관광소비] 탭 + 관광수요 지수(업종별 소비액) | 관광소비 유형·업종별 소비 | ④ 소비성향 프로파일 |
| 지역별 현황 › 성/연령별 방문·소비 현황 | 읍면동 단위 연령·성별 방문·소비 | ④ 연령·성별 프로파일 |
| 방문자기준 지역방문현황 + 이동통신 방문자수 화면(거주지 차트) | 방문자 거주지·유출지 | ④ 출발지 프로파일 |
| 관광수요 지수(관광 이동거리 지표) | 광역시도별 여행거리 상대지수 | ④ 이동거리 프로파일(보조지표) |
| 지역별 현황 › 인기관광지 현황(인기관광지/핫플레이스/방문자 급등 동네) | 세대별 인기지점, 급성장 지점, 내·외국인 급등 행정동 | ⑤ 급증 지점 랭킹 |
| 지역별 관광현황 › [유사 지역] 탭 | 관광진단지표 기준 유사지역 자동 추천(3곳) | ⑥ 유사 지역 선례 |
| 지역별 관광현황 › [유입·유출 지역] 탭 | 주 유입·유출 지역 상위 3곳 | ⑤ 인접 지자체 파급 |
| 관광수요 지수(종합) | 4대분류·8중분류·59개 세부지표 월간 추이 | 위 지표들의 교차검증·보조 근거 |

## 2. 데이터랩 외부 — 정부·공사 시스템

| 수집처 | 데이터 | 활용 용도 |
| --- | --- | --- |
| 관광지식정보시스템(know.tour.go.kr) 주요관광지점입장객통계 | 유료 관광지 입장객 수(지역별현황/통계표/보고서) | ⑤ 급증 지점 랭킹 보완 |
| 공공데이터포털(data.go.kr) | 위 데이터셋 오픈API, 지자체·문화관광공사별 관광 데이터셋 | 자동 수집(API), 지자체 자료 보완 |
| 대한민국 구석구석(korean.visitkorea.or.kr) | 내국인 관심 관광지 조회순위 | ⑤ 급증 지점 랭킹 보완 *(존재 여부 재확인 필요)* |
