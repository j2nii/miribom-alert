## 3. 팀 공통 주의사항

- SNS 관련 모든 분석·서술은 **데이터랩 월별 자료 기준**으로 통일 (일일 자료 사용 금지)
- 검색량·방문자수가 함께 늘어나는 사례는 자동 판정에 의존하지 말고 **반드시 사람이 원인(오탐/바이럴)을 확인** 후 사례 라벨에 반영
- 유튜브 API 수집은 수영이 필요 시 다른 부원에게 요청할 수 있으며, 요청받은 팀원은 우선 협조
