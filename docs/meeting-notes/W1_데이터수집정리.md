# W1 데이터 수집 정리

**기간** 2025.01 ~ 2026.08 · **초점 지역** 거제 + 바이럴 4곳(여수·울릉·속초·소래포구) + 대조군 3곳

## 구조

| 층 | 소스 | 범위 |
| --- | --- | --- |
| 탐지 신호 (일간) | 네이버 검색어 트렌드 API | 전수 |
| 정답 라벨 (월간) | 지역별 방문자수 API | 전수 |
| 공식 교차검증 | 데이터랩 언급량·내비 검색건수 | 표본 15~30곳 |
| 프로파일 | 데이터랩 | 거제 + 대조군 3 |
| 발생 시점 | YouTube | 8곳 |

> 신호와 정답 라벨이 둘 다 API라 전수가 공짜다. 데이터랩은 교차검증 축으로 쓴다.

## 팀원 1 — API·스크립트

1. **네이버 검색어 트렌드** — `timeUnit=date`, 전수 → `naver_daily.csv`
2. **YouTube Data API v3** — 8곳, 영상 게시일·조회수 + 댓글 작성 시각 → `youtube_videos.json` `youtube_comments.json`
3. **뉴스 날짜** — 8곳 보도 날짜·제목·URL → `news_timeline.csv`

## 팀원 2 — 데이터랩 화면

**Day 1 확인 → 즉시 공유**
① 기간 시계열인가 월별 개별인가 (표본 크기가 여기서 결정) ② 2025.01까지 소급되는가 ③ 거제 유사지역 추천 → 대조군 3곳 확정 + 캡처

**표본 15~30곳 (2항목)** — SNS 언급량 · 내비게이션 검색건수
**거제+대조군 3곳** — 성/연령 · 인기관광지(현지인/외지인 구분) · *여유 시* 목적지 유형별 검색량·거주지·거리별·소비유형
**지역별 방문자수 API** (data.go.kr 15101972) — 시군구 월별, 전수 → `visitors_monthly.csv`
**추가** — 거제시 월간 보고서 전 호수 · **컬럼 정의서** · 집중률 API(15128555)

파일명 `{지역}_{항목}_{기간}.csv`

## 주의 4개

- **네이버 앵커 정규화** — 나눠 호출하면 각 호출의 100이 서로 다른 기준. 매 요청에 거제를 넣고 재정규화. 안 하면 전부 다시 받아야 함
- **유튜브 과거 조회수 없음** — 게시일 + 댓글 작성 시각으로 대체. 쿼터 하루 100회(`search.list`), 결과 캐시
- **집중률 API는 향후 30일만** — 과거 시계열 없어 백테스트 불가. 대시보드 데모용
- **방문자수 API 기초·광역 합산 금지** — 집계 기준이 다름. 시군구 단위로만

**Day 1에 공공데이터 API 2종 운영계정까지 신청.** 개발계정 1,000회로는 부족할 수 있고 심의에 며칠 걸린다.
