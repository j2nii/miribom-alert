시계열 분석 진행 사항 공유드립니다.

**한 줄 요약: 방문자 예측 모델을 만들어 기준선보다 오차를 24% 줄였고, "검색이 방문보다 먼저 움직이는가"를 실제로 검증했습니다. 결론은 시군구 단위에서는 아니라는 것입니다.**

## 1. 만든 것

분석 패널과 예측·탐지 코드를 GitHub `analysis/src/forecast/`에 올렸습니다. (develop 머지 완료)

- **분석 패널**: 일별 신호 + 달력 + 날씨 + 축제를 하나로 합친 301,416행 (228개 지역 × 1,322일, 중복 0, 결측 0)
- **예측 모델**: 7일 뒤 외지인 방문자수 예측. 변수를 한 층씩 올리며 개선폭 측정
- **탐지**: 급증 사건 추출과 검색 신호의 선행성 검증
- **검토 도구**: 결과를 믿어도 되는지 스스로 검사하는 코드 5종
- **그림 4장**: 서식4에 바로 넣을 수 있는 상태

## 2. 확인된 결과

**① 방문자 예측이 됩니다 — 기준선 대비 오차 24% 감소**

| 모델 | 예측 오차(sMAPE) |
| --- | --- |
| 작년 같은 요일 그대로 (기준선) | 12.27% |
| **달력 + 방문자 과거값** | **9.27%** |
| + 축제 | 9.24% |
| + 검색 | 9.25% (변화 없음) |

**② 검색 변수는 예측을 개선하지 않았습니다.** 급증일만 따로 봐도, 사례 지역만 봐도, 1일 예측으로 바꿔도 같았습니다. 228개 지역 중 좋아진 곳 85, 나빠진 곳 143입니다.

**③ 검색 신호가 방문 급증을 예고하지도 않았습니다.** 적중률 2.0%인데 아무 날이나 골라도 1.7%가 나옵니다(상승도 1.1배 = 사실상 무작위).

**④ 시군구 방문 급증의 95%는 공휴일이 만듭니다.** 전년 대비 급증 43건 중 41건이 공휴일과 겹쳤습니다.

**⑤ 콘텐츠 효과는 지점에서만 보입니다.** 영월 청령포 입장객이 전년 대비 2월 8.0배·3월 11.9배, 단종장릉 9.1배·13.5배인데, 같은 기간 영월 시군구 전체 외지인 방문자는 1.3~1.4배였습니다.

**⑥ 영월은 검색이 먼저 떴습니다.** 검색 신호 2/15 → 첫 행정 조치 3/6로 19일 앞섰습니다. 다만 사례 한 건이고 신호일이 설 연휴 혼잡과 겹쳐서, "혼잡보다 먼저"가 아니라 "행정 조치보다 먼저"로만 쓸 수 있습니다.

## 3. 분석의 신뢰성을 위해 한 것

숫자가 좋게 나오는 흔한 이유는 모델이 좋아서가 아니라 미래 정보를 몰래 쓰기 때문입니다. 그래서 다음을 지켰습니다.

- **공개 시차 반영**: 방문자수는 4일 지연 공개라 4일 이전 값만, 검색은 전일까지만 사용
- **날씨는 분리**: 일주일 뒤 날씨는 알 수 없으므로 "운영 모델"과 "상한 모델"을 나눔
- **시간 순 분할**: 학습 2023~2024 / 검증 2025 / 테스트 2026 (랜덤 분할 없음)
- **자체 검사 5종**: 시차 정렬·위약 검사·미래 차단·기저율 보정·임계 민감도

**이 검사 덕분에 제 결과 하나를 스스로 철회했습니다.** 처음엔 "공휴일·축제 신호를 걸러내면 경보 품질이 2배"라는 결과가 나왔는데, 비교 기준을 지역별로 바로잡으니 개선이 사라졌습니다(1.99배 → 1.03배). 임계를 바꾸면 결론도 뒤집혔습니다.

## 4. 제안 — 서식4 방향

"검색이 선행 신호"라는 전제는 **시군구 단위에서는** 데이터가 지지하지 않습니다. 대신 이렇게 가는 것을 제안합니다.

> **시군구 총량으로는 안 보이는 쏠림이 지점에서는 8~13배로 나타난다. 그래서 지점 단위 감시가 필요하다.**

검색 관련 서술도 숨기지 말고 "실제로 재봤더니 이랬다"로 쓰는 편이 낫다고 봅니다. 기저율 대비 상승도라는 올바른 잣대를 썼다는 점이 오히려 강점이 됩니다. 심사에서 "검색이 정말 도움이 되나요"라는 질문이 나오면 숫자로 답할 수 있습니다.
