## 0. 이번 주 목표

> **일요일에 데이터가 도착하면, 목업 JSON을 실데이터로 교체하는 것만으로 전체가 살아나는 상태.**

역할 3·4는 데이터가 없어서 막힌 게 아니라, 데이터를 기다릴 필요가 없는 작업이 쌓여 있는 상태다. 이번 주에는 **빈칸이 뚫린 완성품**을 만든다.

## 1. 선행 판단 두 가지

### ① 서식 4 작성은 미루되, 계량성과 항목은 이번 주에 확정

문서 작성을 다음 주로 넘기는 것은 타당하다. 어차피 많이 바뀐다.

다만 **계량성과 항목 4~5개**는 이번 주에 못 박는다. 이건 문서 작성이 아니라 **데이터팀에 대한 지시**다. 무슨 숫자를 낼지 정하지 않으면, 분석이 끝난 뒤에 "이 숫자로 뭘 말하지"가 된다.

→ 일요일 회의 안건으로 30분 배정. 문서 작성은 다음 주.

### ② 매뉴얼 구조화는 통째로 넘기지 않고 분할

| 담당 | 범위 |
| --- | --- |
| **역할 4** | 태그 체계 설계 — 단계/유형/프로파일 축 구분, 필드 구조, 샘플 항목 5개 직접 작성 |
| **데이터팀** | 그 형식대로 매뉴얼 전체 항목 채우기 |

태그 체계까지 넘기면 안 되는 이유: 그것이 곧 **에이전트 ③의 검색 인덱스**다. 프롬프트 설계자가 축을 정해야 매칭이 성립한다. 나머지 수십 개 항목을 채우는 노동만 넘긴다.

**인계 시 주의** — 형식 설명만 보내면 다른 모양으로 돌아온다. 반드시 **샘플 5개 + 필드 설명**을 함께 전달.

샘플 항목 형태:

```json
{
  "id": "CL-023",
  "단계": "주의",
  "유형": ["맛집형"],
  "프로파일": ["20대비중높음"],
  "조치": "...",
  "근거": "매뉴얼 p.47 3.2절"
}
```

`근거` 필드가 핵심. "AI가 정책을 창작하지 않는다"를 화면에서 증명하는 장치.

## 2. 역할 3·4 재분배

분배 기준을 바꾼다. "기획 vs 개발"이 아니라 **경계는 JSON**이다.

| | 역할 4 | 역할 3 |
| --- | --- | --- |
| 소유 | 시스템이 **무엇을 말하는가** | 그것을 **어떻게 보여주는가** |
| 범위 | 에이전트 5종, 프롬프트, 판정·매핑 로직, JSON 출력 규격 | React 5화면, 데이터 로딩, 배포, 시연 |
| 산출 | `*.json` 생성기 + 프롬프트 | 접속 가능한 URL |
| 접점 | JSON 스키마 (공동 확정) | 동일 |

이 구조에서는 역할 4가 프론트를 몰라도 되고, 역할 3은 에이전트 동작을 몰라도 파일만 읽으면 된다. 서로 막지 않는다.

### JSON 파일 구성 (9종)

자연어 질의 인터페이스의 도구 목록과 1:1 대응.

```
signal_status.json     단계, 3중 교차검증 결과, 판정 근거
forecast.json          90일 예측, 요일별 집중률
visitor_profile.json   성/연령·거주지·거리·소비·동반유형
hotspots.json          급증 지점 랭킹 (현지인/외지인 구분)
content_type.json      콘텐츠 유형 분류 + 판단 근거
checklist.json         매칭된 매뉴얼 체크리스트
precedent.json         유사 지역 선례 카드
before_after.json      조치 전후 비교
timeline.json          사례별 타임라인 (에이전트①)
```

**공통 필수 필드**: 모든 파일 최상단에 `data` / `source` / `period` / `caveat`.

가이드라인에 이미 있는 규칙이지만, 스키마 레벨에서 강제해두면 제출 문서에 *"출처 없는 값은 화면에 표시되지 않도록 설계했다"* 고 쓸 수 있다. 신뢰성 항목에서 유효한 서술.

**목업 규칙**: 목업 파일에는 `"_mock": true` 플래그를 넣고, 화면 상단에 샘플 데이터 배지를 띄운다. 목업 스크린샷을 제출물에 넣는 사고 방지.

```
JSON 스키마 확정 (화)
      ├─→ 목업 JSON 9종 (수) ─→ 역할 3 화면 전체 (목~토)
      └─→ 데이터팀 산출물 형식
```
