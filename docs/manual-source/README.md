# 원문 자료

프로젝트의 근거가 되는 원문이다. 구조화 산출물(`manual/`)의 `근거` 필드는 전부 이 문서들의 쪽수를 가리킨다.

## 1. 지속가능한 관광지 혼잡도 운영 관리 매뉴얼

- 발행: 한국관광공사, 2026.03 (57쪽)
- 파일: `지속가능한_관광지_혼잡도_운영관리_매뉴얼.pdf`
- 원본: [한국관광 데이터랩 게시물](https://datalab.visitkorea.or.kr/site/portal/ex/bbs/View.do?cbIdx=1603&bcIdx=310400)
- 이용조건: **공공누리 제4유형** (출처표시 + 상업적 이용금지 + 변경금지)

우리 시스템이 사용하는 기준이 모두 여기서 나온다.

| 내용 | 쪽 |
| --- | --- |
| 관광지 유형 4분류 (정의·특성·관리방안) | 13 |
| KPI 3-tier 11개 지표 | 15 |
| 운영관리 시나리오 7단계 | 20 |
| 혼잡도 단계 1~5 밀도 임계값 (0.2/0.4/0.6/0.8 명/㎡) | 53 |
| 경사 보정 이동 혼잡도 공식 및 감천문화마을 적용 사례 | 53~54 |
| 일일 운영 실무 가이드(체크리스트) 17개 항목 | 50 |
| 용어 정의 24개 | 49 |
| 공공데이터포털 보유 데이터 / 국내 공공분야 오픈 API | 51~52 |

**변경금지 조건**이므로 조치 문장을 요약하거나 다듬지 않는다. 원문을 그대로 옮기고 쪽수를 남긴다.

## 2. 주요 관광지 혼잡도 측정 방안 연구 (최종보고서)

- 발행: 한국관광공사, 2025.02 (192쪽)
- 파일: `주요관광지_혼잡도_측정방안_연구_최종보고서_250217.pdf`
- 원본: [한국관광 데이터랩 게시물](https://datalab.visitkorea.or.kr/site/portal/ex/bbs/View.do?cbIdx=1129&bcIdx=308713)

1번 매뉴얼의 기반이 된 연구보고서다. 매뉴얼이 "무엇을 하라"라면 이쪽은 "왜 그 숫자인가"에 해당한다. 분석 설계·모델 개발 장이 있어 예측 모델 근거로 인용할 수 있다.
