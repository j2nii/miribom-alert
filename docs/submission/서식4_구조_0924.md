## 8. 1) 문제점 또는 현안사항 (10줄)

## 9. 2) 데이터 활용 방안 (18줄) — 데이터 활용도 30점

이 칸의 목표는 "무엇을 썼다"가 아니라 **"어떻게 제대로 썼다"**를 보이는 것이다.

- **분석 단위와 기간**: 228개 시군구 × 1,322일 = 301,416건의 일별 패널 구축 (데이터랩 월간 + 이동통신 일별 + 기상 + 공휴일 + 축제)
- **공개 시점 규칙을 지킨 설계** ← 이 항목이 차별점이다
  - 이동통신 일별 방문자: 4일 지연 공개 → 예측에 4일 이전 값만 사용
  - 데이터랩 월간: 매월 17일 전월분 공개 → 예측 시점에 공개된 달만 사용(실제 사용 자료 나이 51~84일)
  - 날씨: 관측값이지 예보가 아니므로 **운영 모델에서 제외**, 별도 '상한 모델'로만 제시
  - → 백테스트 성능이 실제 운영 성능과 일치하도록 설계
- **시간 순 검증**: 학습 2023~2024 / 검증 2025 / 테스트 2026.1~8 (무작위 분할 없음)
- **데이터별 기여도 정량 측정**: 블록 단위로 넣고 빼며 측정, **위약 대조군**(지역 이름표를 섞은 가짜 데이터)과 비교해 순수 기여만 계상
- **쓰지 않기로 한 데이터와 그 이유**: 뉴스·블로그 수집 데이터는 급증 발생 후 작성된 글이 52.8%이고 수집 표본이 정답 주변에 편중(전체의 1.28%)되어 **모델 입력에서 제외**, 원인 설명 용도로만 사용
