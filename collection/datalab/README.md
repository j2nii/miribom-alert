# 한국관광 데이터랩 공식 다운로드 수집기

한국관광 데이터랩 「지역별 관광현황」에서 지역과 기간을 바꾸고 사이트의
`전체 다운로드` 버튼을 누르는 작업을 자동화합니다. 로그인 정보는 코드나
설정 파일에 저장하지 않습니다.

## 수집 범위

기본 수집 범위는 **2024년 1월~2026년 8월, 총 32개월**입니다. 데이터랩의
월간 조회 한도가 18개월이므로 다음 두 구간을 자동으로 순차 실행합니다.

| 구간 | 기간 | 개월 수 |
|---:|---|---:|
| 1 | 2024-01~2025-06 | 18 |
| 2 | 2025-07~2026-08 | 14 |

두 구간은 합칠 때 중복 월이 없습니다. 2020~2023년은 기본 수집이 끝난 뒤
`08_collect_before_2024_later.cmd`로 추가할 수 있습니다.

## 오늘 실행 순서

명령 프롬프트에서 다음을 실행합니다.

```cmd
cd C:\Users\han\yaho\datalab_collector
py -m pip install -r requirements.txt
py collect_datalab_periods.py --limit 1
```

명령어 대신 `00_setup.cmd`를 한 번 실행한 다음 `01_pilot_1region.cmd`를
더블클릭해도 됩니다. **1개 지역 × 2개 기간**을 시험하며, 시험 성공 후
`02_collect_all.cmd`를 실행합니다. 기존 `01_pilot_5regions.cmd`도 호환을
위해 남겨뒀지만 현재는 동일하게 1개 지역을 시험합니다.

브라우저가 열리면 직접 로그인하고 `지역별 관광현황` 화면으로 돌아온 뒤,
**브라우저 창을 닫지 않은 채** 명령 프롬프트에서 Enter를 누릅니다. 창을
최소화하는 것은 괜찮습니다. 두 기간의 8개 ZIP이 모두 성공하면
전체 수집을 시작합니다.

브라우저 프로필에 아이디와 비밀번호가 자동완성되어 있으면 로그인 폼을
자동 제출합니다. 수집기는 아이디·비밀번호를 코드나 설정 파일에 저장하지
않으며 화면에 자동완성된 값만 사용합니다. 자동완성을 사용할 수 없으면 기존처럼
수동 로그인 안내를 표시합니다.

```cmd
py collect_datalab_periods.py
```

기본 탭은 다음과 같습니다.

| 번호 | 탭 | 월별 핵심 패널 |
|---:|---|---|
| 2 | 방문자 | 포함 |
| 3 | 숙박/체류시간 | 포함 |
| 4 | 관광소비 | 포함 |
| 5 | 소셜미디어 | 포함 |

`전체 다운로드`는 화면에서 선택된 탭만 받으므로 핵심 32개 월별 지표를
갱신하려면 네 탭을 모두 받아야 합니다.

기본값은 로그인 후 데이터랩 지역 선택 창에서 현재 제공되는 지역코드와
지역명을 자동으로 읽습니다. 따라서 인천·화성 등 행정개편으로 바뀐 지역도
사이트의 최신 목록을 그대로 수집합니다. 예전 `region_master.csv`를 강제로
쓰려는 경우에만 `--regions ../region_master.csv`를 지정합니다.

- 세종특별자치시는 사이트의 시군구 목록이 비어 있으므로 시도 코드 `36`으로
  직접 선택합니다.
- 2026-07 이전은 광주 `29xxx`·전남 `46xxx`, 이후는 통합 `12xxx`를 사용합니다.
  개편일을 포함하는 구간은 전후 코드를 모두 받고 병합 단계에서 동일 지역으로
  합칩니다.
- 통합 상위 시와 하위 일반구가 동시에 제공되는 경우 기존 259개 패널과 맞추기
  위해 통합 상위 시(`sggIntgYn=Y`)는 수집 대상에서 제외합니다.

## 이어받기와 실패 재시도

- 성공한 파일은 `progress.jsonl`에 기록됩니다.
- 같은 명령을 다시 실행하면 성공 항목을 건너뛰고 미완료 항목부터 계속합니다.
- 중단·실패 후에는 `03_retry_failed.cmd`를 실행합니다. 성공한 지역·기간·탭은
  건너뛰고 실패 및 미실행 항목부터 이어집니다.

```cmd
py collect_datalab_periods.py
```

- 특정 지역코드부터 시작하려면 `--start-at 11170`을 사용합니다.
- 시험 지역 수는 `--limit 5`처럼 제한할 수 있습니다.

## 결과 확인

```cmd
py inspect_downloads.py datalab_downloads --show-columns
```

결과 폴더에는 원본 다운로드 파일과 다음 진행 기록이 생깁니다.

- `datalab_downloads/progress.jsonl`: 재시작용 전체 이력
- `datalab_downloads/progress_summary.csv`: 지역·탭별 최신 상태

원본 다운로드 파일은 삭제하거나 덮어쓰지 않습니다.

## 병합 및 MySQL 적재

전체 수집 완료 후 다음 순서로 실행합니다.

```cmd
04_merge_downloads.cmd
05_check_mysql_load.cmd
06_load_mysql.cmd
mysql -u yaho_loader -p tour_earlywarning < 07_validate_mysql.sql
```

`04_merge_downloads.cmd`는 두 기간에 걸친 네 탭의 ZIP을
`datalab_monthly_update_202401_202608.csv`로 병합하고 기존
`관광_월별패널_259개지역.csv`의 겹치는 값과 대조합니다. 종로구 파일럿에서는
2025년 9월~2026년 7월의 비어 있지 않은 값이 모두 일치했습니다.

`05_check_mysql_load.cmd`는 CSV 구조만 확인하고 DB를 변경하지 않습니다.
`06_load_mysql.cmd`가 실제 반영 단계입니다. 기존 행은 업데이트하고
2024-01~2025-07 및 2026-08 행을 추가하며, 새 CSV의 빈 값은 기존 DB 값을
지우지 않습니다.

MySQL 접속 정보는 기존 `yaho_mysql_setup\.env`를 사용합니다. 두 폴더가
`C:\Users\han\yaho` 아래에 나란히 있어야 합니다.

정상적으로 사이트 지역 259개가 모두 수집되면 병합 CSV는
`259 × 32개월 = 8,288행`입니다. 기존 DB와 기간이 겹치는 행은 업데이트되고,
최종 데이터랩 테이블도 약 8,288행이 됩니다.

지역화폐 지표는 제공되지 않는 지역이 있으므로 해당 CSV가 없는 경우 빈 값으로
유지합니다. 광주·전남 행정개편 지역은 2026년 6월까지 구 코드를, 2026년 7월부터
신 코드를 사용하며 두 코드의 과거 비교값을 같은 월에 혼합하지 않습니다.
과거 SNS 자료가 제공되지 않아 사이트가 빈 다운로드를 반환하는 경우에도 해당
지역의 다른 지표는 보존하고 SNS 값만 빈 값으로 유지합니다.

## 2020~2023년 추가 수집

2024년 이후 수집·적재를 먼저 끝낸 뒤 필요할 때 다음을 실행합니다.

```cmd
08_collect_before_2024_later.cmd
py merge_datalab_downloads.py --periods 202001:202106,202107:202212,202301:202312,202401:202506,202507:202608
py load_datalab_mysql.py datalab_monthly_update_202001_202608.csv --commit
```

전체 2020-01~2026-08은 80개월이며, 259개 지역 기준 약 20,720행입니다.

## 주의

- Chrome이 없다면 `--browser msedge`를 붙여 실행합니다.
- 로그인 만료 시 브라우저에서 다시 로그인한 후 같은 명령을 재실행합니다.
- 실행 중 로그인 만료가 감지되면 콘솔이 일시정지합니다. 브라우저에서 다시
  로그인한 뒤 콘솔에서 Enter를 누르면 계속됩니다.
- 사이트의 화면 세션 타이머는 3,600초입니다. 수집기는 30분마다 페이지를
  다시 열고 로그인 상태를 확인한 뒤 현재 지역·기간을 복원합니다.
- 예방 갱신에도 세션이 끝난 경우 브라우저에 저장된 자동완성 정보로 로그인을
  한 번 시도하고, 성공하지 못한 경우에만 수동 로그인을 요청합니다.
- 실행 중 브라우저 창이나 프로세스가 종료되면 같은 로그인 프로필로 최대 3회
  자동 재실행하고, 실패한 탭부터 다시 시도합니다. 다시 로그인하라는 안내가
  나오면 새로 열린 창에서 로그인하고 **창을 열어 둔 채** Enter를 누릅니다.
- 연속 5건 실패하면 요청 제한이나 사이트 장애로 보고 자동 중단합니다.
  사이트 상태를 확인한 뒤 같은 CMD를 다시 실행하면 이어받습니다.
- 사이트에 과도한 부하를 주지 않도록 기본 2초 간격을 유지합니다.
- 사이트에서 제공하는 공식 다운로드 버튼만 사용합니다.
