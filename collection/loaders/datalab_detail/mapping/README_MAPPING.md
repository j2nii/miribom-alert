# 데이터랩 지역 매핑 적용

## 적용 내용

- 원천 데이터 `datalab_monthly_panel` 20,720행은 삭제하거나 합치지 않습니다.
- 데이터랩 원천 지역 259개를 분석 정본 지역 228개에 연결합니다.
- 일반구는 상위 시로 묶습니다.
- 인천 개편 전 지역은 2026년 6월까지, 개편 후 지역은 2026년 7월부터 사용합니다.
- 화성시 신설 일반구는 실제 값이 나타나는 2026년 2월부터 사용합니다.
- 분석용 뷰는 정본 지역·월마다 한 행만 반환합니다.

## 실행

이 폴더를 `C:\Users\han\yaho\datalab_mapping`에 풀고 다음 파일을 실행합니다.

```bat
11_apply_datalab_mapping.cmd
```

세 단계마다 `yaho_loader` 비밀번호를 묻기 때문에 총 세 번 입력합니다.

검증 결과에서 다음 값이 나오면 정상입니다.

| 원천 테이블의 NULL 정본 코드 | 0 |
| 분석 뷰 | 18,240행 / 228지역 / 80개월 |
| 정본 지역·월 중복 | 0 |
| 인천 개편 전후 기간 중복 | 0 |

## 팀원에게 안내할 조회 대상

분석에는 다음 뷰를 사용합니다.

```sql
SELECT *
FROM tour_earlywarning.vw_datalab_canonical_monthly
WHERE period_start BETWEEN '2024-01-01' AND '2026-08-01';
```

원천 지역별 값을 확인할 때만 아래 테이블을 사용합니다.

```sql
SELECT *
FROM tour_earlywarning.datalab_monthly_panel;
```

`vw_datalab_canonical_monthly`의 집계 원칙은 다음과 같습니다.

- 방문자, SNS, 검색량, 소비금액: 합계
- 전년동월 증감률: 합계된 현재값과 전년값으로 재계산
- 숙박일수, 체류시간, 비율: 방문자수 가중평균
- 전국 대비 소비 비율: 하위 지역 비율 합계
- 순방문자수: 일반구 사이에서 같은 사람이 중복될 수 있어 여러 지역이 합쳐지는 경우 `NULL`
- `is_aggregated_region=1`: 둘 이상의 원천 지역이 합쳐진 정본 지역
- `unique_visitors_available=0`: 순방문자수를 안전하게 합산할 수 없는 지역
