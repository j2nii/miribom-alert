# 원본 스캔 검증 결과

패키지 작성 환경에서 제공받은 원본을 `--scan-only`로 실제 해석한 결과입니다.

| 원본 | 확인 결과 |
|---|---:|
| DataLab 샘플 4개 ZIP | 31 CSV · 2,139행 |
| 포털추가수집.zip | 33개 파일 |
| 포털 카탈로그 | 32행 |
| 거주지별 내국인 관광객 | 80행 |
| 제주 관광지 일별 입장객 | 6,640행 |
| PDF 참고자료 | 30개 |
| 관광지식정보시스템_데이터.zip | 19개 파일 |
| 실측 방문자 사례 | 6행 |
| 관심 관광지 순위 | 원천 120행 · 동일 파일 중복 제거 후 DB 60행 |
| 주요 관광지 월별 입장객 | 847,656행 |
| 관광지 XLS | 16개 |

관광지 XLS 중 7개는 2004년 7월부터 2026년 6월까지, 나머지 9개는 제공 파일 기준 2025년 1월부터 2026년 6월까지 들어 있습니다. 파일명만 보고 기간을 가정하지 않고 각 XLS의 월 헤더를 읽어 적재합니다.

전체 DataLab 수집 폴더는 사용자 PC에 있으므로 최종 행 수는 `02_scan_received.cmd`에서 확정됩니다. 이 스캔은 DB를 변경하지 않습니다.
